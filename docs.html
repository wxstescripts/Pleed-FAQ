Getting Started

1. Invite Pleed to your Discord server.

2. Give Pleed the required permissions.

3. Run:

/setup

to begin configuration.

Permissions

Pleed requires permissions depending on enabled features.

  • Manage Messages
  • Manage Channels
  • Moderate Members
  • View Audit Logs

Ticket Setup

Create a professional support system.

/ticket setup

Customize:

  • Support roles
  • Ticket categories
  • Access permissions

Moderation Setup

Configure:

  • Warnings
  • Logs
  • Auto moderation
  • Staff actions

Security Features

Pleed protects communities with:

  • Anti raid
  • Scam detection
  • Security logging

FAQ

Does Pleed store messages?

Only when required for enabled features.

Can I request my data deleted?

Yes through the Pleed support server.
