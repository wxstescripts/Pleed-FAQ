Pleed Privacy Policy

How we collect, use, and protect your data.

Information We Collect

Pleed collects minimal data necessary to function across Discord servers:

  • User IDs: To manage user settings, permissions, economy balances, and ticket systems.
  • Guild (Server) IDs: To save server configurations, anti-nuke rules, and custom prefixes.
  • Command Inputs: Processed in real-time to execute bot commands.

Data Usage & Protection

  • Data is strictly used to deliver core bot functionality and server configurations.
  • All data is stored securely on private server infrastructure.
  • We do not sell, trade, or share user data with any third parties.

Data Removal & Rights

Server owners can clear server data by removing Pleed. To request a complete deletion of user data, contact us directly via our support server.
