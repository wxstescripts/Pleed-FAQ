Pleed Documentation

Everything you need to set up and run Pleed in your server — 600 commands across moderation, security, economy, automation, tickets, voice, and more. Pick a section below, or use the full command browser for a live searchable list.

Quick facts — Default prefix: ! (change it anytime with !prefix <new_prefix>). Slash commands (/) work alongside prefix commands. Most moderation and configuration commands require the relevant Discord permission (Manage Server, Manage Roles, Administrator, etc.) — Pleed will tell you if you're missing one.
