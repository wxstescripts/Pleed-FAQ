Getting Started with Pleed

A quick walkthrough for adding Pleed to your server and getting it configured.

1. Invite the bot

Use the Invite button on the homepage, or go straight to the OAuth invite link. Grant Administrator (recommended for full moderation/antinuke coverage) or a curated set of permissions if you prefer to scope it down manually.

2. Check your prefix

Pleed responds to prefix commands (default !) and slash commands (/). Both work side by side — use whichever is faster for a given command.

CommandDescription
!prefix <new_prefix>Change the server's command prefix.
!help [command_name]Open the interactive help menu, or look up one command.
!helpsetupOpen the help panel configuration.
!ai <question>Ask Pleed's built-in AI assistant a question.

3. Run the setup wizard

Most modules have their own guided setup command rather than a dozen manual config commands. Start with the server setup wizard, then layer on the specific modules you want:

  • !setup — general first-time server configuration (see Server Setup).
  • !setupticket — create your first ticket panel (see Tickets).
  • !antinuke enable — turn on raid/nuke protection (see Security).
  • !automationsetup — toggle auto-moderation and automation features (see Automation).
  • !voicemaster setup command — enable temp voice channels (see Voice).

4. Understand permissions

Every command that changes server settings checks your Discord permissions before running (usually Manage Server, Manage Roles, Manage Channels, or Administrator, depending on the command). If a command silently refuses to run, check that both you and Pleed's role have the permission needed, and that Pleed's role sits above any roles it needs to manage.

Role hierarchy matters. For moderation actions (ban, kick, timeout, jail, role management) Pleed's own role must be positioned above the target member's highest role in Server Settings → Roles, or the action will fail.
