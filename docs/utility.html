Information & Utility

Lookups, profile tools, snipe (recover deleted/edited messages), highlights, image utilities, and general server/member info — 102 commands for everyday use.

Grab a member's avatar or profile banner.

Set an AFK status shown when you're mentioned.

!ping

Check bot latency.

Snipe (recover deleted content)

Snipe lets you look back at deleted messages, edits, and ghost pings in a channel:

  • !snipe [index] — the last deleted message in this channel (or the Nth back).
  • !editsnipe [index] — the last edited message.
  • !ghostsnipe [index] — pings that were deleted quickly ("ghost pings").
  • !guildsnipe [index] — deleted messages anywhere in the server, not just the current channel.
  • !usersnipe <member> [index] — filter sniped messages down to one member.
  • !bulksnipe [index] — recover a bulk-delete event.
  • !snipesearch <query> — search sniped content by keyword.
  • Paginated browsing panels: !snipepanel, !editsnipepanel, !ghostpanel, !reactionhistorypanel.
  • Cleanup: !clearsnipe, !cleardeletedsnipes, !cleareditsnipes, !clearghostsnipes.

Highlights

Get notified (via DM) when a keyword you care about is mentioned, even if you weren't tagged: !highlight add <keyword>, view them with !highlight list, and use !highlight ignore [target] to mute notifications from a specific member, channel, or role.

Social & game lookups

Pull public profile info from other platforms without leaving Discord: !roblox <username> (plus fromdiscord/todiscord account linking and outfits), !minecraft <username>, !steam <steam_id>, !github <username>, !osu <username> [game], !valorant <user>, !xbox <gamertag>, !snapchat <username>, !telegram <username>, and !cashapp <username>.

Image tools

Quick image manipulation straight in chat: !invert [url], !rotate <degree> [url], !compress <ratio> [url], !hex [target] (grab a dominant color), and !screenshot <url> to capture a website.

Emoji & stickers

Server emote/sticker management: !emoji add <emoji> [name], !emoji addmany <emotes>, !emoji rename, !emoji removeduplicates, and the equivalent !sticker add/remove/rename/cleanup set for stickers.
