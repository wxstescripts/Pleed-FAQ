Server Setup

Server Setup

First-time configuration: the setup center, welcome/goodbye messages, invite tracking, and the update logger for announcing changes to your community.

The setup center

Rather than hunting for individual config commands, !setup opens a panel that links out to every setup flow. If you just want jail/mute infrastructure created quickly:

  • !setupjail — creates the jail channel and role.
  • !setupmute — creates the mute role and channel permissions.
  • !setupall — runs both jail and mute setup together.
  • !setupstatus — check what's already configured.
  • !fixjailperms — re-apply jail role permission overwrites across every channel if something looks off.
  • !jailroles [state] — toggle whether jailing a member also strips their existing roles.

Welcome & goodbye messages

Configured under the !messages group:

!messages welcomechannel <channel>

Set where welcome messages post.

!messages welcomemessage <text>

Set the welcome message text.

!messages welcometoggle <state>

Turn welcome messages on/off.

!messages testwelcome [member]

Preview the welcome message.

!messages goodbyechannel <channel>

Set where goodbye messages post.

!messages goodbyemessage <text>

Set the goodbye message text.

!messages goodbyetoggle <state>

Turn goodbye messages on/off.

!messages testgoodbye [member]

Preview the goodbye message.

Update logger

Post polished, templated changelog announcements to your community. Set it up once with /setup_updates <channel> [role] [footer], then either open the full builder with /post_update or fire off a fast one with /quick_update <title> [overview] [added] [fixed] [improved] [removed] [notes]. Save reusable presets with /save_update_template and /save_update_theme (color, emoji, footer), review past posts with /update_history, and fix mistakes with /edit_last_update or /delete_last_update.

Invite panel & guild announcements

!addbotpanel / !refreshbotpanel manage an invite-tracking panel, and !guildinform / !guildmessage <member> handle server-wide announcement messaging.
