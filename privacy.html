Privacy Policy for Pleed

Last Updated: September 3, 2026

1. Information We Collect

Pleed collects minimal data necessary to function properly across Discord servers:

  • User IDs: To save user preferences, balances, permissions, and ticket details.
  • Guild (Server) IDs: To store server-specific settings, log channels, and anti-nuke configurations.
  • Command Inputs: Processed in real-time to execute requested actions.
  • Public Server Stats: Names, icon URLs, and member counts displayed on our server showcase.

2. How We Use Information

Data is used exclusively to deliver bot functionality, retain server configurations, display website statistics, and ensure system security.

3. Storage & Security

All data is stored securely on private server infrastructure with strict access controls to prevent unauthorized access.

4. Data Sharing

We do not sell, share, or transfer user or server data to any third parties.

5. Data Removal & User Rights

Administrators can clear server data by removing the bot. Users may request complete data deletion by contacting staff on our official support server.
