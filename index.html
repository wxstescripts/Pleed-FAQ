Introduction

Pleed is a Discord bot designed to provide moderation, automation, ticketing, security, and community management features.

This Privacy Policy explains what information Pleed collects, why it is collected, and how users can request removal of data.

Information We Collect

  • Discord User IDs
  • Discord Server IDs
  • Channel and Role IDs
  • Bot configuration settings
  • Moderation records
  • Ticket system information
  • Feature-related data

Information We Don't Collect

  • Passwords
  • Payment information
  • Private conversations
  • Personal information unrelated to Discord

How Data Is Used

Information is used only to provide Pleed features such as:

  • Server moderation
  • Security protection
  • Ticket management
  • User settings
  • Automation features

Message Processing

Some features may temporarily process messages to detect commands, spam, scams, or security threats.

Messages are not permanently stored unless required by a specific feature.

Data Security

Pleed takes reasonable steps to protect stored information. However, no online service can guarantee complete security.

Data Deletion

Users and server administrators may request deletion of stored data by contacting the Pleed development team.
