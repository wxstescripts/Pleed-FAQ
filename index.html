Pleed Privacy Policy

Effective Date: July 24, 2026

1. Introduction

Pleed ("the Bot", "we", "us", or "our") is a Discord bot designed to provide server management, moderation, automation, ticketing, and utility features. This Privacy Policy explains what information Pleed collects, how it is used, and how users can request deletion of their data.

2. Information We Collect

Pleed may collect and store limited information required for its features, including:

  • Discord User IDs
  • Discord Server (Guild) IDs
  • Channel IDs
  • Role IDs
  • Bot configuration settings
  • Moderation records such as warnings or security actions
  • Ticket system information
  • Economy, leveling, or feature-related data if enabled by a server administrator

Pleed does not collect passwords, payment information, private messages, or personal information unrelated to Discord functionality.

3. How We Use Information

Collected information is used only to operate and improve Pleed's features, including:

  • Providing moderation tools
  • Managing server configurations
  • Creating and managing tickets
  • Maintaining user settings and progress
  • Preventing abuse and protecting servers

4. Message Data

Some Pleed features may process message content temporarily to detect commands, moderation violations, spam, scams, or security threats. Message content is not permanently stored unless required for a specific feature and configured by the server owner.

5. Data Storage and Security

Data is stored securely using database systems required for Pleed's operation. Reasonable measures are taken to protect stored information, but no online service can guarantee complete security.

6. Third-Party Services

Pleed operates through Discord's platform and may use third-party hosting or database services to provide functionality. These services may process information necessary for the bot to operate.

7. Data Deletion Requests

Users or server administrators may request deletion of stored data by contacting the Pleed development team through our support server.

8. Children's Privacy

Pleed does not knowingly collect personal information from children. Discord's own Terms of Service and age requirements apply when using the platform.

This Privacy Policy may be updated periodically. Continued use of Pleed after changes means you accept the updated policy.
